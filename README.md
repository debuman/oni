# oni

> Static Git browser written in Rust.

Inspired by [stagit](https://codemadness.org/stagit.html).
Running at [oni.sqzer.com](https://oni.sqzer.com).

## Features

- Repository index, commit history, diffs, files, branches, and tags
- Rendered READMEs and source archives
- Atom feeds and pull request listings
